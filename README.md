# GeminiCord - AI in discord, but better 🧠
Version v5 is now released (if you see this message)! This version includes many new features, and a complete rewrite of the code from the ground up!

## About
Welcome, to the documentation for **GeminiCord v5.0.0**! This is the *new* and *improved* iteration of your favorite (or perhaps least favorite, depending on your tolerance for digital sarcasm) Discord bot.

Developed and programmed purely by me, [turtledevv](https://github.com/coolboy67yt), this bot is the best AI discord bot out there... Well, perhaps that's quite a big statement, but it's
jam packed with features.

With the new v5 version, bugs have been fixed, code rewritten, features added, and more.

## What's new in v5?
As cool and old as v2-v4 was, we have to all admit. It barely worked. It was buggy. Unoptimized. Unorganized.
Just a simple python file held together by scotch tape and Github Copilot.

In v5, I decided to remake all of the code from the ground up, and yes. ALL OF IT.
If you have your config from v4.3.0 and below and want it ported over.. Good luck!
I wish you the best. Shouldn't be too hard. I think.

## Setup (Once it's Ready)
In theory, it should involve cloning the repository, setting up a virtual environment, installing dependencies from `requirements.txt`, configuring the YAML file. Super easy if you know what you're doing.
